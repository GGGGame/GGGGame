## 🚀 Main project — Nolxy

[**Nolxy**](https://nolxy.com) is a production-grade API gateway and management platform I designed and built from scratch.

- High-performance routing with Fastify, ~0.01ms warm-path latency
- Multi-layer DDoS protection (iptables, TCP termination, application-level banning)
- Two-tier hybrid caching (in-process LRU + Redis)
- Real-time analytics pipeline with 30+ fields per request via ClickHouse
- Atomic quota enforcement with Redis Lua scripts
- Gateway as Code with CI/CD integration via Service Accounts
- Auto-generated OpenAPI 3.0 specs and per-user developer portals
- Webhook delivery with payload signing, retries, and Datadog log streaming
